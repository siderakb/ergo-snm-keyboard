# 軌跡球高度降低：斜置 PMW3610 研究紀錄（擱置中）

狀態：2026-11-07 討論後**先擱置**，模型沒有修改。以下是當時的估算和結論，之後重新評估時從這裡接續。

距離都是沿拇指面法線 n、從球心往下量（mm）；換算成垂直高度大約要再乘 cos 20° ≈ 0.94。數值是手算估計，還沒有用 CAD 驗證。

## 現況：深槽最低點的組成

| 項目 | mm |
| :--- | ---: |
| 感測器堆疊：球半徑 17 + 工作距離 2.4 + 鏡頭 3.4 + PCB 1.6 + FPC 座 2.0（朝下） | 26.4 |
| 拇指排線的底部間隙 `BALL_POD_FLOOR_CLEAR` | 1.5 |
| 底殼壁厚 `BOTTOM_WALL` | 2.0 |
| **合計** | **≈ 29.9** |

工作距離、鏡頭、PCB 合計 24.4 是光學決定的，不能縮。

## 各種感測器擺法的最低點

| 擺法 | 感測器最低點 | 比現況 | 韌體 |
| :--- | ---: | ---: | :--- |
| 現況：垂直、原廠模組、FPC 朝下 | 26.4 | — | 不用改 |
| 垂直、自製板、FPC 移到上方那一面 | 24.4 | −2.0 | 不用改 |
| 30°，原廠模組 23.5 × 31.5 | 27.0 | +0.6（更低） | 要補償 |
| 30°，自製窄板 | 23.7 | −2.7 | 要補償 |
| 45°，自製窄板 | 20.8 | −5.6 | 要補償 |

- 斜置時，板子較低的那一角會往下掉，所以原廠模組斜放反而更低。斜置要有效，必須自製窄板：鏡頭短邊（8.1）朝下、靠近板子較低的那一側（邊距約 1 mm），FPC 座移到上面那一面。
- 板子較低那一角的深度 = 24.4 · cos θ + (4.05 + 邊距) · sin θ。

## 斜置對韌體的影響（ZMK）

傾斜方向對齊感測器的其中一軸時：

- 在傾斜平面內的那個軸：讀到的是 R · ω_y，**沒有縮放，也沒有混入自轉**。
- 垂直於傾斜平面的那個軸：讀到的是 R · (cos θ · ω_x + sin θ · ω_z)，**被縮成 cos θ，而且混入了 sin θ 的自轉**。
- 縮放可以用 `zip_x_scaler` / `zip_y_scaler` 補償（30° 時用 15/13）。但補償後，自轉的比例會變成 tan θ，而且韌體無法分辨自轉和正常滾動。

| θ | 補償倍率 | 補償後的自轉比例 | 左右撥時帶 10% 自轉，游標的偏移角 |
| :--- | ---: | ---: | ---: |
| 30° | 1.155 | 0.58 | ≈ 3° |
| 45° | 1.414 | 1.00 | ≈ 6° |
| 55° | 1.743 | 1.43 | ≈ 8° |

## 目標「整體降 10 mm」的評估

目標是最低點從 ≈ 29.9 降到 ≈ 19.9 以內。

感測器斜放之後，會出現兩個新的限制：

1. **球杯底部**：17 + 0.8 + 1.5 + 0.5（離深槽）+ 2.0（壁厚）= 21.8，已經超過目標。要把球杯底部挖空，只留一圈環（滾珠在 60° 時本來就不需要杯底）。這樣最低點變成球本身：17 + 1.0 + 2.0 = 20.0。
2. **45° 感測器板較低的那一角**：20.8 + 0.5 + 2.0 = 23.3，還差約 3.4。

可以補這段差距的調整：

| 調整 | 效果 | 代價 |
| :--- | ---: | :--- |
| 窄板鏡頭邊距 1.0 → 0.5 | −0.3 | 板邊會很靠近鏡頭的卡扣 |
| 深槽在感測器那一角開窗，板邊外露，外面貼薄膜 | −2.0 | 要另外做防塵和絕緣 |
| 球心再往上抬（`BALL_RAISE` 5 → 7～8） | 每抬 1 mm 降 1 mm | 球頂會比鍵帽高 7～8 mm |
| 球縮小到 30 mm | ≈ −2 | 換球、手感改變 |
| 深槽下方那顆腳柱拿掉，在深槽底部直接嵌腳墊 | −0.5～1 | 支撐點要重新檢查 |
| 斜置角度加大到 55° | ≈ −3 | 自轉比例 1.43，不建議 |

組合估算：

- **A（保留 34 mm 球）**：45° 自製窄板 + 球杯挖成環 + 鏡頭邊距 0.5 + 開窗外露 + 球心抬 2 mm + 腳墊嵌在深槽底部 → 約降 11 mm。
- **B（不抬球、不外露）**：45° 自製窄板 + 球杯挖成環 + 30 mm 球 + 腳墊嵌在深槽底部 → 約降 8.6 mm，還要再加開窗或抬球其中一項才能到 10 mm。

## 重新評估前要先確認

1. **斜置方向只能沿著拇指臂（±u）。** 45° 的板子水平會伸出到離球軸約 25 mm，但拇指臂內牆離軸只有 18.98 mm，往兩側（±v）斜，深槽會突出到拇指臂外面。
2. **深槽抬高之後，可能就不再是最低點。** 主體底板、其他腳柱、拇指區牆的下緣都可能變成新的高度限制。要拿 `trackball.lowest_points()` 和其他部位的最低點一起，算出新的桌面平面，確認實際能降多少，再決定值不值得做。
3. 不改韌體的第一步，就是「自製板 + FPC 移到上方 + 拇指排線改走其他路線」，可以降約 3 mm，可以單獨先做。
